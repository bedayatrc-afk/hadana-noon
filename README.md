# منصة حضانة نون — نسخة محسّنة

مشروع Django باللغة العربية مع واجهة RTL وثيم أخضر زمردي وذهبي، وتحسينات للأدوار، وتسجيل المصروفات، وقائمة المدفوعات، والتقارير اليومية.

## التشغيل على Windows / VS Code

افتح PowerShell داخل المجلد الذي يحتوي على `manage.py` ثم نفّذ:

```powershell
py -m venv venv
.\venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
Copy-Item .env.example .env
python manage.py check
python manage.py migrate
python manage.py runserver
```

ثم افتح `http://127.0.0.1:8000/` في المتصفح.

> لو ظهر منع لتشغيل التفعيل في PowerShell، نفّذ داخل نافذة الطرفية الحالية فقط: `Set-ExecutionPolicy -Scope Process -ExecutionPolicy RemoteSigned`، ثم أعد أمر التفعيل.

## البريد الإلكتروني

الإعداد الافتراضي للتطوير يستخدم Console backend، لذلك لا يُرسل بريدًا إلى الإنترنت. صفحة إرسال التقييم تتحقق من إعدادات SMTP ولا تعرض رسالة نجاح مضللة عندما تكون بيانات البريد فارغة. لإرسال بريد حقيقي، افتح ملف `.env` وأدخل `EMAIL_HOST_USER` و`EMAIL_HOST_PASSWORD` باستخدام **App Password جديد** من مزوّد البريد، وليس كلمة مرور حسابك العادية. لا ترفع `.env` إلى GitHub.

## البيانات وقاعدة البيانات

تحتوي هذه النسخة على قاعدة البيانات التي كانت ضمن الأرشيف للمحافظة على البيانات الحالية. خذ نسخة احتياطية من `db.sqlite3` قبل إجراء أي تغييرات كبيرة أو قبل النقل إلى بيئة إنتاج. عند إعداد نسخة جديدة تمامًا، يمكن إنشاء قاعدة بيانات جديدة بتشغيل `python manage.py migrate` بعد مراجعة بيانات المشروع.

## ملاحظات أمان مهمة

- لا تستخدم `DJANGO_DEBUG=True` على خادم عام.
- اضبط `DJANGO_SECRET_KEY` و`DJANGO_ALLOWED_HOSTS` في البيئة الفعلية.
- تم نقل بيانات SMTP من ملف الإعدادات إلى متغيرات البيئة؛ غيّر/ألغِ App Password القديم الذي كان موجودًا في النسخة الأصلية قبل الاعتماد على الإرسال الحقيقي.
- إرسال البريد الحقيقي يحتاج بيانات SMTP صحيحة واتصالًا يسمح به مزود البريد.

## ما تم تغييره

- توحيد سجل الرسوم الذي تستخدمه صفحة تسجيل الدفع وقائمة المدفوعات.
- تقييد بعض الصفحات والتقارير حسب دور المستخدم، وإصلاح ربط ولي الأمر بالطالب.
- إصلاح حفظ التقارير اليومية التي كانت تمرر اسم الطفل بدل كائن الطالب المرتبط بقاعدة البيانات.
- إضافة نموذج لإدخال المصروفات، وقوالب تغيير كلمة المرور المشار إليها في الروابط.
- إعدادات بيئية للأسرار والبريد، إعدادات عربية وتوقيت القاهرة، وإتاحة ملفات الإيصالات في وضع التطوير.
- إضافة نظام CSS موحد متجاوب للصفحات الموجودة.

## الاختبار

تمت مراجعة الملفات وتعديلات الكود بشكل ساكن داخل هذه البيئة. لم أتمكن من تشغيل أوامر Django الفعلية هنا لأن Django ومكتبات المشروع غير مثبتة، وبيئة التنفيذ لم تستطع الوصول إلى فهرس الحزم؛ نفّذ `python manage.py check` محليًا أولًا، ثم `python manage.py migrate`، وأرسل أي رسالة خطأ تظهر لك لإكمال المعالجة.
